Architectural Pillars

Lean, predictable agent execution optimized for consumer hardware.

⚡

Zero Intermediate Abstractions

Bypasses multi-layered Node.js/Python frameworks in favor of a single, static Go binary that talks directly to llama-server over HTTP.

🎯

Hardware-Aware Tiering

Probes GPU VRAM, CPU vector extensions (AVX2/AVX-512), and RAM to configure optimal model weights, KV cache quantization, and context length.

💻

Constrained Hardware Support

First-class support for 4GB VRAM mobile dGPUs (such as GTX 1650 Max-Q) using 3B Q4 models with dedicated pure-VRAM Q4_0 KV caching.

🛡️

Deterministic Tool Calling

Eliminates JSON formatting hallucinations on small 7B/3B models via explicit action delimiters (<action>) and native Go mechanical tools.

📁

XDG Standard Compliance

Strict adherence to XDG Base Directory specification: unprivileged non-root install in ~/.local/bin and clean state partitioning.

🔌

In-Repo MCP Facades

Provides invariant tooling surfaces for memory, AST outlining, and noise-gated test verifications without bloating context.

One-Line Installation

Install lokol directly into your user home directory conforming to XDG standards.

curl — installer
